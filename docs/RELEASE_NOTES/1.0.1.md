# DP Autoclicker 1.0.1

Автономный Windows-сборка: **Python на компьютере не нужен**.

## Скачать

- **Windows:** `DP_Autoclicker.exe` — один файл. Двойной клик для запуска.

В `.exe` уже встроены Python, PySide6 и pynput (PyInstaller `--onefile --windowed`), как в DP Typing Master.

Windows может показать предупреждение SmartScreen — это ожидаемо для неподписанных сборок. Разрешите запуск, если доверяете источнику.

## Что изменилось

- Точка входа `DP_Autoclicker.py` и сборка по образцу DP_Typing_Master
- Явная проверка размера артефакта в CI
- Установка пакета перед PyInstaller для надёжного сбора модулей

## Что внутри

- Плавающее полупрозрачное окно поверх всех окон
- Точки нажатия с прицелом и лупой
- Визуальный конструктор алгоритмов и текстовый скрипт (RU/EN)
- Рандомизация координат и пауз (выключена по умолчанию)
- Переносимые пресеты `*.dpclick.json`
- Страховка от вмешательства мышью, сухой прогон, горячие клавиши

## Запуск из исходников (разработчикам)

```bash
python -m pip install -r requirements.txt
python DP_Autoclicker.py
```
