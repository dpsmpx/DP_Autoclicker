# DP Autoclicker 1.0.0

Первый публичный выпуск.

## Скачать

- **Windows:** `DP_Autoclicker.exe` (один файл, из исходников через PyInstaller).

После загрузки Windows может показать предупреждение SmartScreen — это ожидаемо для неподписанных сборок. Разрешите запуск, если доверяете источнику.

## Что внутри

- Плавающее полупрозрачное окно поверх всех окон
- Точки нажатия с прицелом и лупой
- Визуальный конструктор алгоритмов и текстовый скрипт (RU/EN)
- Рандомизация координат и пауз (выключена по умолчанию)
- Переносимые пресеты `*.dpclick.json`
- Страховка от вмешательства мышью, сухой прогон, горячие клавиши

## Запуск из исходников

```bash
python -m pip install -r requirements.txt
python run.py
```

Нужен Python 3.9+. Лицензия: GPL-3.0-or-later.
