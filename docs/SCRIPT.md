# DPScript — язык алгоритмов DP Autoclicker

Скрипт и дерево блоков на вкладке «Алгоритм» — одно и то же. Всё, что можно
собрать мышью, можно написать текстом, и наоборот.

Ключевые слова понимаются на двух языках. Ниже основной вариант русский, в
скобках — английский.

---

## Действия

### Клик

```
клик Точка1
клик Точка1 кнопкой правая
клик Точка1 раз 3
клик Точка1 кнопкой средняя раз 2 удерживая 300мс
```

| Часть | Смысл |
|---|---|
| `клик` (`click`) | нажатие мышью |
| `кнопкой` (`with`) | `левая`/`лев`/`лкм`, `правая`/`пкм`, `средняя`/`скм` |
| `раз` (`times`) | сколько нажатий подряд |
| `удерживая` (`hold`) | долгое нажатие; без него — из настроек рандомизации |

### Движение и перетаскивание

```
навести Точка2                  # мгновенно
навести Точка2 за 300мс         # плавно
перетащить Точка1 к Точка2
перетащить Точка1 к @(400, 300) за 600мс кнопкой левая
```

`навести` = `move`, `перетащить` = `drag`, `к` = `to` (можно `->`), `за` = `in`.

### Кнопка мыши по частям

```
зажать левая на Точка1
навести Точка2
отпустить левая
```

`зажать` = `press`/`down`, `отпустить` = `release`/`up`, `на` = `at`.

### Прокрутка, клавиши, текст

```
прокрутить 3                    # вверх
прокрутить -5 на Точка1         # вниз, предварительно наведя курсор
клавиша enter
клавиша ctrl+shift+s
печатать "привет, мир"
```

`прокрутить` = `scroll`, `клавиша` = `key`, `печатать` = `type`/`write`.

Имена клавиш: буквы и цифры, `f1`…`f12`, `enter`, `esc`, `tab`, `space`,
`backspace`, `delete`, `insert`, `home`, `end`, `pageup`, `pagedown`,
`up`/`down`/`left`/`right`, модификаторы `ctrl`, `alt`, `shift`, `win`.

## Паузы

```
ждать 500мс
ждать 2с
ждать 100мс..900мс      # случайное значение из диапазона
```

`ждать` = `wait`/`pause`. Единицы: `мс`/`ms`, `с`/`s`/`сек`, `мин`/`min`.
Число без единицы в `ждать` считается секундами.

## Повторы

```
повторить 10 раз {
    клик Точка1
    ждать 200мс
}

цикл {                  # до остановки вручную
    клик Точка1
    ждать 1с
}

пусть i = 0
пока i < 5 {
    пусть i = i + 1
    клик Точка1
}
```

`повторить` = `repeat`, `цикл` = `loop`, `пока` = `while`.

Внутри любого цикла доступна переменная `итерация` (`iteration`) — номер
текущего круга, начиная с 1.

> Цикл, который за три круга подряд не выполнил ни одного действия,
> останавливается с ошибкой — это защита от зависания.

## Условия

```
если шанс(30%) {
    клик Точка2
} иначе если итерация > 5 {
    клик Точка1
} иначе {
    ждать 1с
}
```

`если` = `if`, `иначе` = `else`.

## Переменные и выражения

```
пусть счётчик = 0
пусть счётчик = счётчик + 1
пусть задержка = 100мс * 3
```

`пусть` = `set`.

**Операторы** (по возрастанию приоритета): `или` (`or`), `и` (`and`),
`не` (`not`), сравнения `== != < <= > >=`, `+ -`, `* / остаток` (`mod`),
унарный минус, скобки.

**Значения:** числа (`10`, `2.5`), длительности (`500мс`, `1.5с`), проценты
(`30%` → `0.3`), строки (`"текст"`), логические `да`/`нет` (`true`/`false`),
диапазоны `a..b`.

**Встроенные переменные:**

| | |
|---|---|
| `итерация` (`iteration`) | номер круга текущего цикла |
| `время` (`elapsed`) | секунд с начала работы |
| `действий` (`actions`) | сколько действий уже выполнено |

**Функции:**

| | |
|---|---|
| `шанс(p)` (`chance`) | истина с вероятностью `p` — например `шанс(25%)` |
| `случайно(a, b)` (`random`) | случайное число в промежутке |
| `мин(a, b)`, `макс(a, b)` (`min`, `max`) | наименьшее / наибольшее |
| `округлить(x)` (`round`), `модуль(x)` (`abs`) | округление, модуль |

## Управление выполнением

```
прервать        # выйти из текущего цикла      (break)
стоп            # остановить весь алгоритм     (stop)
сообщение "…"   # запись в журнал              (log / say)
```

## Точки и координаты

Цель действия — имя точки со вкладки «Точки» либо явные координаты:

```
клик Кнопка_ОК
клик @(1280, 720)
клик @(960 + смещение, 540)
```

Имя точки может содержать буквы (в том числе кириллицу), цифры и `_`, но не
может начинаться с цифры и не может совпадать с ключевым словом языка.
Переименование точки на вкладке «Точки» автоматически обновляет все ссылки
в алгоритме.

## Комментарии

```
# отдельная строка
клик Точка1     # примечание к строке
```

Комментарии сохраняются при переключении между конструктором и текстом.

## Полный пример

```
# Собираем ресурсы и раз в пять кругов проверяем инвентарь
повторить 20 раз {
    клик Кнопка_действия
    ждать 400мс..900мс

    если итерация остаток 5 == 0 {
        клик Кнопка_проверки кнопкой правая
        ждать 1с
        клавиша esc
    }

    если шанс(15%) {
        ждать 2с..4с        # изредка «отвлекаемся»
    }
}
сообщение "Готово, действий: " + действий
```
